# Onboarding Kit

Work through these files whenever you onboard a new client:

1. `client_profile_template.md` – capture the internal record: contacts, desired schedules, env vars.
2. `client_connection_checklist.md` – collect concrete DB credentials, networking requirements, delivery channels, and compliance notes.
3. `client_setup.md` – follow the step-by-step instructions to create `envs/clients/<client>.env`, schedule wrappers, and first jobs.

Archive the completed templates in your internal system and copy only the necessary secrets into the repo's env files.
